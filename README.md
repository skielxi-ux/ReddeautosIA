# Red de Autos · Tucumán

Marketplace automotor inverso con IA: el comprador escribe o dicta qué auto busca y su presupuesto; la plataforma le muestra autos reales de agencias de Tucumán o activa una alerta de compra por WhatsApp.

- `index.html` — buscador (Tailwind + GSAP + Swiper + Lucide), conectado a Supabase.
- `privacidad.html` — política de privacidad.

Sitio: https://skielxi-ux.github.io/ReddeautosIA/
